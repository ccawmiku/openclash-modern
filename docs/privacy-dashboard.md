# 隐私仪表盘与证据口径

2026-10-04。预览入口 `/#security`；保护与采集设置 `/#privacy-settings`，节点监控设置 `/#node-settings`。两类设置均是独立页面，直接打开和刷新有效。设置表单不会与仪表盘同时挂载，离开仪表盘停止前端轮询。

## 从仪表盘看什么

| 项目 | 证据 | 不能推导的结论 |
| --- | --- | --- |
| 加密、明文、未知比例 | WAN 出站捕获记录；可切换记录数／字节数 | TLS 握手不能证明握手成功、证书验证、全部正文加密或远端可信 |
| 协议分布 | TLS、明文 HTTP/DNS、QUIC、不完整握手、未识别 TCP/UDP | 端口 443、疑似 DoH 或 QUIC 不自动等同已确认安全 |
| 五分钟趋势 | 后台最多 60 个快照的当前缓存记录数 | 不是新增事件数或完整网络吞吐，缺失样本不补零 |
| LAN／WAN 明文 DNS | 观察位置、DNS 元数据与连接关联 | LAN 向路由器发起明文查询不等于校园网泄露 |
| 国内外 DNS 证据 | 可读域名与近期同域名内核地理判定关联 | 加密查询内的域名不可被动读取，不能逐条保证全部国内外查询安全 |
| 国外 SNI 可见 | Clash 地理判定＋WAN ClientHello 中可读 SNI | 没有读到 SNI、提出 ECH 或 TLS 1.3，都不证明域名隐藏成功 |
| 国外站点直连 | Clash 地理判定＋实测／内核报告的直连路径 | DNS 上游查询不是网站直连；直连也不自动代表违规或危险 |
| 覆盖状态 | 接口、数据新鲜度、卸载、丢包、分片、容量、内核可用性 | 一个配置 WAN 接口不等于任意多出口全覆盖 |

环图使用当前缓存，连接闲置五分钟后淘汰；持续活动连接的字节可能跨越更长时间。因此比例不是严格滑动五分钟的吞吐比例。LAN 副本不重复加到 WAN 字节，目标为本地地址的常见 LuCI/SSH 响应从比例排除，但保留在连接证据表。

## 复用内核国内外判断

只读取标准 `/connections` 的实际命中规则、规则内容和目标 GeoIP。明确的 GeoSite 国内／国外类别优先；否则使用实际 GeoIP 命中或目标国家代码。混合或缺失证据为未知。不会以 DIRECT 代表国内、PROXY 代表国外，也不猜名为 China、Global 等自定义规则集的含义。

接口依据：[官方 API 文档](https://github.com/MetaCubeX/Meta-Docs/blob/main/docs/api/index.md)、[Mihomo 1.19.32 metadata 定义](https://github.com/MetaCubeX/mihomo/blob/v1.19.32/constant/metadata.go)。目标 GeoIP 可以为空，表示内核尚未查询；这时无法额外承诺任意域名分类。这里不加载独立 APNIC 数据、不下载另一套网站库、不为分类访问外部服务。代理关闭时基础抓包和 DNS 防护继续工作，地理证据可能不足，界面明确显示未知。

同域名证据只在 RAM 保留最多五分钟、最多 4096 条；矛盾证据记未知，不扩展到未观测过的其他域名或子域名。网站规则类别与目标地址地理信息不代表网站公司国籍。

## 连接详情与监控维护

风险卡、协议条和地域筛选可定位到连接列表。详情展示域名、内核规则／规则内容、节点链、实际路径与关联依据、WAN 暴露证据、接口位置和端点；不提供误导性的综合安全分。统计和元数据不写闪存，不保存应用正文或 API 密钥。

国内 DoH 仍为阿里主用、腾讯 DNSPod 备用，固定自举和证书验证。独立服务不依赖代理启动；全部端点不可用时继续阻断外部明文 DNS。此次调整没有改写防护规则或替换 MetaCubeXD。

## 验证与边界

`privacy-dashboard-test.json` 覆盖真实快照、计数与字节合计、协议／地域筛选、设置保存与非法拒绝、独立路由刷新、停止轮询、桌面和 390px 布局。环图数值、风险详情、未知状态、趋势断线另用浏览器隔离夹具验证，不向服务写入假数据。

`privacy-analytics-test.json` 覆盖 14 类内核判定、证据冲突和未知处理。`privacy-monitor-integration.json` 使用隔离 API、conntrack、捕获夹具执行真实快照函数，验证 NAT 与 SNI、明文 DNS 同域名关联、去重、管理流量排除及 DNS 不误算网站直连。测试不创建真实泄露或改动生产网络。

实际接口与采集能力的限制依然存在，QUIC/ECH 接受、未知隧道、多 WAN、流量卸载及全部应用行为不能被当前被动观察完全证明。生产硬件尚未部署验证。
