# 界面层级与记录操作

更新于 2026-10-04。本轮修改保留原生字段和写入逻辑，调整展示、组织及记录创建流程。原版 MetaCubeXD 与独立 DNS、隐私观察、节点历史模块继续独立维护。

## 首页

运行状态与当前配置并列。八项统计为上传、下载、累计上传、累计下载、连接数、系统内存、系统 CPU 与一分钟负载。流量计数来自标准 Mihomo API，系统指标来自 proc；流量只覆盖内核连接，不能冒充整个路由器的 WAN 吞吐。

流量图保留本页最近六十次采样，每五秒一次。内核不可用的样本不连线，不补零；没有持久化五分钟图表历史。首页展示代理模式、接管方式、维护快捷操作、四网站检查及自定义域名测试。四个出口服务一次并发查询，逐项呈现状态；查询由路由器发起，不代表每个客户端的实际出口。

常用控制默认展开。上游项目和贡献者只显示在首页。

## 设置

第一层为插件设置、覆写设置、订阅设置、节点与策略组、配置与文件管理、代理 Provider 文件、规则 Provider 文件七个可见入口。侧栏节点策略页限定于节点工作区，避免同时展示无关模型。

第二层为各模型的业务分类，第三层在需要时使用主题导航。简单设置直接选择参数，不强行套用记录层。

DNS 解析下分解析行为、Fake-IP 与过滤、备用解析过滤、按域名分配 DNS、静态 Hosts、上游服务器。上游进一步分常规、备用、自举、直连域名、节点域名五种用途；每页六条服务器卡片。选择记录后显示该记录的基础字段，完整详情继续分地址与协议、用途与出站、加密与响应选项。

这里是 OpenClash 内核 DNS 配置。代理关闭后仍运行的加密 DNS 保护在独立隐私监控页；两者不能混为同一个启用开关。

## 新增与详情

添加按钮先打开草稿表单，填写基础参数；可选的协议参数置于草稿的高级区。读取草稿元数据不调用真实 UCI 创建、保存或提交。前后端验证合法值、原生依赖和必要字段，成功后才创建记录。取消或非法提交不产生空记录。

保存后定位新记录及所在页。卡片明确显示名称、地址或用途，并提供完整详情、排序和删除；启用开关写明作用于这个服务器、账号或记录。只读摘要没有可编辑参数时直接进入完整详情，避免无效参数按钮。详情返回恢复分组、记录和页码。

字段说明默认展开。格式与合法范围合并为填写要求；开关只保留用途与建议，操作按钮只保留用途。空接口显示自动选择接口，列表值显示数量与摘要。配置文件的只读状态、时间、大小按文件集中展示，不占用参数编辑列表。

订阅自动更新展示组合计划：执行日期可以为每天或每周指定日，执行时刻是这些日期上的小时，两者共同决定计划，不是两个相互竞争的周期。
